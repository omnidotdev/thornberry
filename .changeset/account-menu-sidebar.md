`AccountMenu` takes `variant="sidebar"`: a full-width row with the avatar, name, and email for a sidebar footer, opening the same menu to the right and shrinking to the avatar in a collapsed icon sidebar.

`WorkspaceSwitcher` workspaces take an optional `slug`, shown as `@handle` under each name in the list, and the "Manage workspaces" link is now a menu entry you can reach with the keyboard.
