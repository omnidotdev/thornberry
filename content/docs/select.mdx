## When to use NativeSelect vs Select

Use [NativeSelect](/native-select) for plain form choices; it is the default. It is a real `<select>`, so it submits with forms, opens the OS picker on phones, and gets keyboard and screen reader support from the browser. Use this Select when options need rich custom rendering (icons, descriptions, avatars, or a styled dropdown list) or multiple selection.

## Usage

```tsx
import { ChevronsUpDown } from "lucide-react";

import { Button } from "@/components/ui/button";
import {
  createListCollection,
  Select,
  SelectContent,
  SelectControl,
  SelectIndicator,
  SelectItem,
  SelectItemGroup,
  SelectItemIndicator,
  SelectItemText,
  SelectLabel,
  SelectPositioner,
  SelectTrigger,
  SelectValueText,
} from "@/components/ui/select";

```

```tsx
const SelectExample = () => {
  const priorityCollection = createListCollection({
    items: [
      { label: "Low", value: "low" },
      { label: "Medium", value: "medium" },
      { label: "High", value: "high" },
    ],
  });

  return (
    <Select
      positioning={{
        strategy: "fixed",
        placement: "bottom-end",
      }}
      collection={priorityCollection}
      loopFocus
    >
      <SelectLabel>Priority</SelectLabel>
      <SelectControl>
        <SelectTrigger asChild>
          <Button variant="outline" className="w-48 hover:bg-transparent">
            <SelectValueText placeholder="Select priority" />
            <SelectIndicator>
              <ChevronsUpDown />
            </SelectIndicator>
          </Button>
        </SelectTrigger>
      </SelectControl>

      <SelectPositioner>
        <SelectContent className="w-48 p-0">
          <SelectItemGroup className="space-y-1 p-1">
            {priorityCollection.items.map((priority) => (
              <SelectItem key={priority.value} item={priority}>
                <SelectItemText>{priority.label}</SelectItemText>
                <SelectItemIndicator />
              </SelectItem>
            ))}
          </SelectItemGroup>
        </SelectContent>
      </SelectPositioner>
    </Select>
  );
};
```

### Options shorthand

For a single choice from a flat list of strings, `OptionsSelect` renders the label, trigger, portaled list, and hidden native select, and fills its container like an input. Options take an optional `hint` (list only) and `disabled`. Pass `id` to point an external `Label` at the trigger, `size="sm"` for dense rows, `sameWidth={false}` when the options are wider than a compact trigger, `title` for a trigger tooltip, `required` for form validation, and `positionerClassName` to lift the list above a product overlay. An empty `value` shows the placeholder, so use a stand-in value (e.g. `"none"`) for a real "None" option.

```tsx
import { OptionsSelect } from "@omnidotdev/thornberry/select";

<OptionsSelect
  label="Cadence"
  value={cadence}
  onValueChange={setCadence}
  placeholder="Pick a cadence"
  options={[
    { value: "weekly", label: "Weekly" },
    { value: "monthly", label: "Monthly", hint: "Most popular" },
  ]}
/>
```
