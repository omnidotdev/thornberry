## Usage

```tsx
import { ToggleGroupItem, ToggleGroupRoot } from "@/components/ui/toggle-group";
```

```tsx
<ToggleGroupRoot defaultValue={["left"]}>
  <ToggleGroupItem value="left">Left</ToggleGroupItem>
  <ToggleGroupItem value="center">Center</ToggleGroupItem>
  <ToggleGroupItem value="right">Right</ToggleGroupItem>
</ToggleGroupRoot>
```

The group allows one item at a time by default. `value` is always an array of the active item values. Set `variant` and `size` on the root to style every item; an item can override them.
