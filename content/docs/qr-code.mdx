title: QR Code
description: Renders a value as a scannable QR code, with error correction levels and an optional centered overlay such as a logo.

import { Download } from "lucide-react";

  QrCode,

  QrCodeFrame,

  QrCodeRoot,
} from "@/registry/thornberry/components/qr-code";

## Usage

```tsx
import { QrCode } from "@/components/ui/qr-code";
```

```tsx
<QrCode value="https://thornberry.omni.dev" />
```

`value` can be any text: a URL, an `otpauth://` URI for an authenticator app, a Wi-Fi configuration string. The code always renders black on a white, padded background, since scanners expect dark modules on a light background, so it stays scannable under a dark theme. Pass `label` to give the image a descriptive accessible name.

#### Error Correction

`errorCorrection` sets how much of the code can be damaged or covered and still scan: `L` (7%, the default), `M` (15%), `Q` (25%), or `H` (30%). Higher levels draw denser codes.

#### With Logo

`overlay` centers content, such as a logo, over the code. Error correction defaults to `H` when an overlay is set so the covered modules can be recovered; keep the overlay under about a fifth of the code's width.

#### Download

Compose the parts to add a `QrCodeDownloadTrigger`, which saves the code as an image. It must sit inside `QrCodeRoot`; `fileName` and `mimeType` are required.

<Tabs items={["Preview", "Code"]} className="mt-4">
  <Tab value="Preview">
    <QrCodeRoot
      value="https://thornberry.omni.dev"
      encoding={{ ecc: "M" }}
      className="flex-col gap-3 bg-transparent p-0"
    >
      <div className="rounded-md bg-white p-3">
        <QrCodeFrame aria-label="Thornberry website" className="size-40">
          <QrCodePattern />
        </QrCodeFrame>
      </div>
      <QrCodeDownloadTrigger fileName="thornberry.png" mimeType="image/png">
        <Download className="size-4" aria-hidden="true" />
