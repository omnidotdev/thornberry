## Usage

```tsx
import { Splitter } from "@/components/ui/splitter";
```

```tsx
<Splitter
  className="h-64"
  panels={[
    { id: "sidebar", label: "Sidebar", defaultSize: 30, minSize: 20, content: <Sidebar /> },
    { id: "editor", label: "Editor", content: <Editor /> },
  ]}
/>
```

Sizes, `minSize`, and `maxSize` are percentages of the splitter. Panels without a `defaultSize` share whatever the sized panels leave. The splitter fills its parent, so give it (or the parent) a height.

Drag a divider to resize, or focus it and use the arrow keys (hold Shift for larger steps). Home and End jump the panel to its minimum and maximum size. Each divider is labelled from the `label`s of the panels on either side.

#### Collapsible

Mark a panel `collapsible` to let it snap shut when dragged past half its `minSize`, or when its divider is focused and Enter is pressed. `collapsedSize` sets the size it collapses to (0 by default).

#### Composition

Build the layout from the parts. Each `SplitterResizeTrigger` takes the `id` pair of the panels it sits between.

<Tabs items={["Preview", "Code"]} className="mt-4">
  <Tab value="Preview">
    <div className="h-56 rounded-md border">
      <SplitterRoot
        panels={[{ id: "a", minSize: 20 }, { id: "b", minSize: 20 }]}
        defaultSize={[50, 50]}
      >
        <SplitterPanel id="a" className="flex items-center justify-center bg-muted text-sm font-medium">
          A
        </SplitterPanel>
        <SplitterResizeTrigger id="a:b" aria-label="Resize A and B">
          <SplitterResizeTriggerIndicator />
        </SplitterResizeTrigger>
        <SplitterPanel id="b" className="flex items-center justify-center text-sm font-medium">
          B
        </SplitterPanel>
      </SplitterRoot>
    </div>
  </Tab>
  <Tab value="Code">
    ```tsx
    import {
      SplitterPanel,
      SplitterResizeTrigger,
      SplitterResizeTriggerIndicator,
      SplitterRoot,
    } from "@/components/ui/splitter";

    <SplitterRoot
      panels={[{ id: "a", minSize: 20 }, { id: "b", minSize: 20 }]}
      defaultSize={[50, 50]}
    >
      <SplitterPanel id="a">A</SplitterPanel>
      <SplitterResizeTrigger id="a:b" aria-label="Resize A and B">
        <SplitterResizeTriggerIndicator />
      </SplitterResizeTrigger>
      <SplitterPanel id="b">B</SplitterPanel>
    </SplitterRoot>
    ```
  </Tab>
</Tabs>
