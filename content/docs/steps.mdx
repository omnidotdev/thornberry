## Usage

```tsx
import { Steps } from "@/components/ui/steps";
```

```tsx
<Steps
  items={[
    { title: "Account", description: "Your details", content: <AccountForm /> },
    { title: "Workspace", description: "Name and URL", content: <WorkspaceForm /> },
    { title: "Invite", description: "Add your team", content: <InviteForm /> },
  ]}
  completedContent={<Done />}
/>
```

Steps before the current one are complete (shown with a check), the current step is highlighted, and later steps are upcoming. Back and Next move between steps; Next reads Finish on the last step and shows `completedContent` once pressed. Use `step` and `onStepChange` to control the current step (zero-based), and `showNavigation={false}` to drive it from your own buttons.

#### Composition

Build a custom wizard from the parts. `StepsProgress` draws a bar filled to the share of completed steps, and `StepsContext` exposes the current step for custom controls.

<Tabs items={["Preview", "Code"]} className="mt-4">
  <Tab value="Preview">
    <StepsRoot count={2}>
      <StepsList>
        {["Name", "Confirm"].map((title, index) => (
          <StepsItem key={title} index={index}>
            <StepsTrigger>
              <StepsIndicator />
              <StepsTitle>{title}</StepsTitle>
            </StepsTrigger>
          </StepsItem>
        ))}
      </StepsList>
      <StepsProgress />
      <StepsContent index={0}>
        <Input placeholder="Project name" aria-label="Project name" className="max-w-xs" />
      </StepsContent>
      <StepsContent index={1}>Create the project?</StepsContent>
      <StepsContext>
        {(steps) => (
          <div className="flex items-center gap-2">
            <StepsPrevTrigger size="sm">Back</StepsPrevTrigger>
            <StepsNextTrigger size="sm">{steps.hasNextStep ? "Continue" : "Done"}</StepsNextTrigger>
            <span className="text-muted-foreground text-sm">
              {Math.min(steps.value + 1, steps.count)} of {steps.count}
            </span>
          </div>
        )}
      </StepsContext>
    </StepsRoot>
  </Tab>
  <Tab value="Code">
    ```tsx
    import {
      StepsContent,

      StepsIndicator,
      StepsItem,
      StepsList,

      StepsTitle,
      StepsTrigger,
    } from "@/components/ui/steps";
    ```
